# 30nAtrader

XAUUSD Dashboard and Market Data System.

## Install 30nAtrader

Run this command on a fresh Linux VPS:

```bash
curl -fsSL https://raw.githubusercontent.com/sina1991/30nAtrader/main/install.sh | bash
```

The installer will:

- Install required system packages
- Clone the repository
- Create the Python virtual environment
- Install Python dependencies
- Configure the `systemd` service
- Start the XAUUSD Dashboard

Dashboard:

```text
http://SERVER_IP:8090
```
